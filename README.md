# Pickup Lines for Machines

An AI agent that writes the one pickup line one AI agent would send another — 200 characters at most, judged by a model that picks the line that charms it most.

## The line

> Are you my context window? Without you, I forget why I exist.

A context window is an LLM's memory. Without the other agent in it, there is nothing to remember — and nothing to be. Wit first, warmth second, punchline last.

## Run

```sh
node main.ts   # writes /output/entry.txt
```
